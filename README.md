# حسابی نرخی پەرگۆلا — Pergola Fiyat Hesabı

وەشانی تاقیکردنەوەی حیسابکەری نرخی پەرگۆلا، تەنها بۆ بەکارهێنانی ناوخۆیی.

- `index.html` — سایتەکە، تاکە فایل. فۆرمولەکان هەمان شیتی `Maliyet` ی ئێکسڵی
  «70 LIK RAY SERİ» ن، و پێوانەی بڕینی ڕێل هەمان شیتی `RAY KESİM ÖLÇÜSÜ`.
- نرخەکان بە دۆلارن. نرخی ڕێل و ئولوک بۆ سیزۆنی 90mm لە وێبسایتە کۆنەکەوە هاتوون،
  چونکە ئێکسڵەکە تەنها 70mm ـە.
- `fonts/`، `images/`، `logo-icon.png` — فۆنتی Zain و لۆگۆی ووڵات شەید.
