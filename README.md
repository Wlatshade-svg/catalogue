## سێ ڕەهەندی

چوار مۆدێل: بایۆکلیماتیک، پەرگۆلای کارەبایی، کەپری ڕێکی، سکایلایت.
هەموویان دوگمەی «کردنەوە» و «داخستن» یان هەیە. لیستەکە: `ORDER` لەناو JS.

- **بایۆکلیماتیک:** پەڕەکان بەدەوری ناوەندی خۆیاندا دەسووڕێن و بۆ سەرەوە
  دەکرێنەوە. گۆشەی کردنەوە: `Math.PI * 0.46` لەناو `buildBio`.
- **باکگراوند:** کەشێکی گرادیێنتی تاریک، سێبەری ڕاستەقینە لەسەر زەوی، و
  بازنەیەکی ڕووناکی نەرم. لەناو `initThree` دان.

## پەڕەی بارکردن (لۆدینگ)

نیشانەکە پڕ دەبێت، پیتەکانی WLAT SHADE یەک بە یەک بەرز دەبنەوە، و هێڵێکی
پێشکەوتن لەگەڵ ژمارەکە لە خوارەوە. کۆدەکە لەناو `.loader` ی CSS و
`window.addEventListener('load')` ی JS دایە.

## وێنەی سەرەکی (هیرۆ)

`images/hero.jpg`. ڕوونی و شوێنی بڕین: `#top .hero-img` لەناو CSS.

## ڕووە شووشەییەکان

دوگمە ڕوونەکان و بەشەکانی ژمارە و ئیشارەتەکانی ڤیوەر ڕەنگی `rgba(8,7,10,…)`
بەکاردەهێنن. ژمارەی کۆتایی بەرزتر = تاریکتر.

## گۆڕینی ناوەکان

`const PRODUCTS` — هەر سیستەمێک `name:{ku,en,ar}` ی هەیە.
بۆ گۆڕینی «سابت» بۆ «ماتۆڕ»: لیستی `FIXED` لەناو `openGallery`.

## وێنەکان

ناوی وێنەکان: `<ناوی سیستەم>-01.jpg`, `-02.jpg` … یەکەم وێنە وێنەی کارتەکەیە.
بۆ زیادکردن: وێنەکە بخە ناو `images/` و ناوەکەی بخە ناو `GALLERIES`.
