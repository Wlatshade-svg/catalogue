# 3D دیزاینی پەرگۆلا — WLAT SHADE

وەشانی تاقیکردنەوەی سیمیولەیتەری 3D ی پەرگۆلای بایۆکلیماتیک.

- `index.html` و `app.js` — سایتەکە. مۆدێلەکە بە three.js لەناو وێبگەڕدا دروست دەکرێت.
- `vendor/` — three.js 0.160.0 (مۆڵەتی MIT)، لێرەدایە تا سایتەکە پشت بە سێرڤەرێکی تر نەبەستێت.
- هەر دیزاینێک لینکێکی خۆی هەیە (`#c=...`) کە دەتوانرێت بنێردرێت بۆ کڕیار.
